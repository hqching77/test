    本地打开

    四种方式，按需选。要玩 AI 助手就用第 4 种，其余三种只影响页面本身。

    1 · 直接双击

    在文件管理器里双击 index.html，用默认浏览器打开。

    最简单；但地址栏是 file:///…，AI 助手只能走"浏览器直连"并需要填 Key。

    2 · VS Code 预览

    VS Code 里右键 index.html → Open with Live Server，或装 "Live Preview" 插件后点右上角预览图标。

    改代码即时刷新，写页面最舒服。

    3 · 纯静态服务

    在项目目录执行 python -m http.server 8000，然后访问 http://localhost:8000。

    最接近真实部署环境。本机有 Python 3.14，直接可用。

    4 · 带 AI 代理启动 ★

    执行 python server.py，访问 http://localhost:8000。

    除了发静态文件，还多一个 /api/chat 转发口：请求由 Python 代发，顺手解决浏览器跨域（CORS）问题， API Key 也从环境变量 PARATERA_API_KEY 读，不用写进页面。
